# UM982 RTK 生产工装操作说明

> 适用飞控：**EFT_CAAC**（X6100 等）  
> 工装脚本：`1um982_config.lua`  

---

## 一、这套工装是干什么的

飞控接上 UM982 RTK 模块后，脚本会自动完成：

1. 识别 RTK 是否在线  
2. 按 Holybro 标准下发配置（输出 GPGGA、UNIHEADINGA 等，COM1 波特率 230400）  
3. 校验模块是否持续输出正确数据  
4. 用 **WS2812 状态灯** 告诉产线结果：**红 = 未通过，蓝 = 进行中，绿 = 合格**

**产线只需看灯，不必开电脑、不必手动敲命令。**

---

## 二、硬件连接

| 项目 | 说明 |
|------|------|
| RTK 模块 | UM982（Holybro H-RTK 等） |
| RTK ↔ 飞控 | 接 **SERIAL7（UART7 / RTK 口）**，10pin GH 接口 |
| 状态灯 | WS2812 灯带接 **PWM13**，DIN 方向勿接反 |
| 天线 | 主天线 + 副天线（双天线）都要接好，航向数据需要双天线 |
| 供电 | RTK 与飞控共地；建议 RTK **先上电 3～5 秒** 再判结果 |

```
UM982 COM1 ──→ 飞控 SERIAL7（RTK 口）
WS2812 DIN ──→ 飞控 PWM13
5V / GND 共地
```

## 三、首次准备（工艺/测试员做一次即可）

### 3.1 烧录带工装脚本的固件

- 固件需包含脚本 `1um982_config.lua`（编译进 ROMFS 或放 SD 卡 `/APM/scripts/`）
- **不要** 同时加载 `ws2812_fc_status_led.lua`（会抢同一路灯）

### 3.2 工装专用参数（Mission Planner → 全部参数表）

| 参数 | 工装值 | 说明 |
|------|--------|------|
| `SCR_ENABLE` | **1** | 开启 Lua 脚本 |
| `SERIAL7_PROTOCOL` | **28** | Scripting 串口（工装必须） |
| `SERIAL7_BAUD` | **230** | 230400 波特率 |
| `SERVO13_FUNCTION` | **94** | PWM13 驱动 WS2812（Scripting1） |

> 注：Mission Planner 里 **230 = 230400**，**115 = 115200**。

改完参数后 **写入并保存**，然后 **重启飞控**。

### 3.3 确认脚本在运行

重启后 GCS 消息栏应出现类似：

```
UM982工装: 口 0 探测 @230400
UM982工装: 探测 RTK...
```

若出现 `LED: Waiting SERVOx_FUNCTION=94`，说明 `SERVO13_FUNCTION` 未设为 94。

## 四、产线操作步骤（每块 RTK）

### 步骤 1：接线

1. RTK 接到飞控 **RTK 口（SERIAL7）**  
2. 双天线接好，尽量能收到卫星（室内窗口边或室外更佳）  
3. WS2812 灯带已接 PWM13  
4. 给飞控 + RTK 上电  

### 步骤 2：看灯等结果

| 灯色 | 含义 | 操作 |
|------|------|------|
| **红灯常亮** | RTK 未识别 / 最终未通过 | 查接线、供电、天线；排除故障后脚本会自动重试 |
| **蓝灯常亮** | 正在配置或等待校验 | **正常，请等待**，不要拔线（最长约 1～2 分钟） |
| **绿灯常亮** | **合格** | 可以取下，贴合格标，装下一台 |

### 步骤 3：判定合格

**同时满足以下两点即为合格：**

- 状态灯 **绿灯常亮**  
- GCS 出现：`UM982工装: 通过 — GPGGA + UNIHEADINGA 正常`  
  或：`UM982工装: 已配置，直接通过`（模块之前已配好时）

### 步骤 4：装下一台

- 绿灯状态下可直接换下一台 RTK 测试  
- 若换模块后长时间红灯，等 10～15 秒再判；仍红灯则查该台 RTK 接线

## 五、自动流程说明（了解即可）

脚本按 Holybro 文档顺序执行，与 Uprecise 手动配置一致：

```
FRESET
GPGGA COM1 0.2
GPRMC COM1 0.2
AGRICA COM1 0.2
GPGSA COM1 0.2
GPGST COM1 0.2
UNIHEADINGA COM1 0.2
config com1 230400
saveconfig
```

之后在校验阶段确认能收到 **GPGGA（位置）** 和 **UNIHEADINGA（双天线航向）**。

**典型耗时：**

| 阶段 | 大约时间 |
|------|----------|
| 探测 RTK | 5～15 秒 |
| 下发配置 | 约 20 秒 |
| 校验数据 | 最多 45 秒 × 最多 3 次重试 |

已配置过的模块可能 **10 秒内直接绿灯**。

## 六、GCS 消息对照

| 消息 | 含义 |
|------|------|
| `UM982工装: RTK 已识别 @230400` | 找到模块，且已在 230400 |
| `UM982工装: RTK 已识别 @115200` | 找到模块，在 115200（出厂默认） |
| `UM982工装: 开始配置 @... (含FRESET)` | 开始整轮配置（含恢复出厂） |
| `UM982工装: 开始配置 @...` | 重试配置（不再 FRESET） |
| `UM982工装: FRESET 后按 115200 发配置` | FRESET 完成，在 115200 下发命令 |
| `UM982工装: 切到 230400` | 波特率已切到 230400 |
| `UM982工装: 校验输出 @230400` | 正在等 GPGGA + UNIHEADINGA |
| `UM982工装: 校验重试 1/3 @230400` | 第一次校验超时，自动再等（勿拔线） |
| `UM982工装: 通过 — GPGGA + UNIHEADINGA 正常` | **合格** |
| `UM982工装: 已配置，直接通过` | 模块已是正确配置，**合格** |
| `UM982工装: 校验超时，缺 GPGGA+UNIHEADINGA` | 两种数据都没收到 |
| `UM982工装: 校验超时，缺 UNIHEADINGA` | 有位置无航向，查双天线 |
| `UM982工装: 数据中断，请检查 RTK 连接` | 合格后数据断了，查线 |

## 七、常见问题

### Q1：一直红灯，提示「尝试 115200 / 230400」

**可能原因：**

- RTK 未接好或没供电  
- 接错口（必须 SERIAL7 / RTK 口）  
- RTK 刚上电未就绪  

**处理：** 查线 → RTK 单独上电等 5 秒 → 飞控重启；不必反复拔插。

---

### Q2：蓝灯很久不变绿

**可能原因：**

- `saveconfig` 后模块在重启、搜星  
- 室内卫星少，或 **双天线航向** 解算慢  
- 脚本会自动重试校验（最多 3 次），**先等满约 2 分钟**

**处理：** 天线挪到窗边/室外；确认副天线已接。

---

### Q3：提示「缺 UNIHEADINGA」

**可能原因：**

- 副天线未接或线缆不良  
- 双天线距离/安装不符合要求  
- 无足够卫星，RTK 航向未解算  

**处理：** 查双天线接线 → 挪到开阔处再测。

---

### Q4：之前测通过，换台又红灯

每台 RTK 独立测试；换台后等探测完成。若某台长期红灯，为该台 RTK 或线缆问题，不是上一台残留。

---

### Q5：能不能和正常飞行脚本一起用？

**不能。** 工装阶段：

- 只加载 `1um982_config.lua`  

---

## 八、工装完成后（出厂参数恢复）

单台 RTK 测 **绿灯** 后，该 RTK 已写入 Holybro 标准配置（COM1 = 230400）。  
整架飞机出厂前需把飞控参数改回飞行模式：

| 参数 | 出厂值 | 说明 |
|------|--------|------|
| `SERIAL7_PROTOCOL` | **5** | GPS 口（不再是 Scripting） |
| `SERIAL7_BAUD` | **230** | 保持 230400 |
| `GPS_TYPE` | **24** 或 **25** | UM982 双天线 |
| 工装脚本 | **移除或禁用** | 改加载 `ws2812_fc_status_led.lua` 等正常脚本 |

## 九、快速检查清单

**开工前（每班/每台飞控工装架）：**

```
□ 固件含 1um982_config.lua，无 ws2812_fc_status_led.lua
□ SCR_ENABLE = 1
□ SERIAL7_PROTOCOL = 28，SERIAL7_BAUD = 230
□ SERVO13_FUNCTION = 94
□ WS2812 接 PWM13，灯珠数量与脚本 NUM_LEDS 一致（默认 8）
```

**每块 RTK：**

```
□ RTK 接 SERIAL7，双天线接好
□ 上电后蓝灯 → 等绿（约 1～2 分钟）
□ 绿灯 + GCS「通过」→ 合格
□ 长时间红灯 → 查线/天线，勿频繁拔插
```
