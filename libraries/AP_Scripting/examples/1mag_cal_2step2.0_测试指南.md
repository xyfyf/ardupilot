# 磁罗盘两步式快速校准脚本测试指南 (v2.2 低门槛)

本脚本 (`1mag_cal_2step2.0.lua`) 通过**机头朝下持续 5 秒**自动触发校准。**v2.2 已降低门槛**：只校主罗盘、`retry=0` 不重采、`AUTO_ROT=0`、每步 45s。

校准本身仍是飞控原生的 `CompassCalibrator`：连续采样 → 球面拟合 → 椭球拟合 → 自动保存。脚本只负责"姿态触发 + 提示节奏"，不改变飞控的拟合算法。

## 1. 触发与底层命令

| 行为 | 触发条件 | 实际动作 / 播报 |
|---|---|---|
| 启动校准 | 上锁 + `pitch < -60°` 持续 5s | `MAV_CMD_DO_START_MAG_CAL` (mask=0/all, retry=1, autosave=1) |
| 成功播报 | `COMPASS_OFS_X/Y/Z` 任一变化 > 1 mGauss | `磁罗盘成功 偏置=...,...,...`（severity=2，地面站红字优先级显示） |
| 失败播报 | HOLD 阶段结束（65s）仍无 offset 变化 | `磁罗盘失败:偏置未保存`（severity=3） |
| 结束并允许下次触发 | `pitch > -30°` 持续 2s | 状态机回到 IDLE，`磁罗盘:已就绪 可再次触发` |
| 解锁中触发 | — | 拒绝并提示 `磁罗盘:请先上锁` |
| 校准中解锁 | — | 自动 `cancel`，`磁罗盘:已取消 已解锁` |
| 启动失败 | `gcs:run_command_int` 返回非 0 | `磁罗盘:启动失败(N)`，进入 DONE 等姿态放平后再试，避免反复刷屏 |

> STATUSTEXT 字段限制 50 字节，每条中文提示控制在 12–14 个汉字以内。

## 2. 测试前准备

1. **参数已生效**（已在 `EFT_CAAC/defaults.parm` 中默认下发）：
   - `SCR_ENABLE = 1`
   - `COMPASS_CAL_FIT = 32`（Relaxed，因为 2 圈覆盖比 6 面少）
   - `COMPASS_OFFS_MAX = 1800`
   - 无需 `RCx_OPTION` 配置
2. 把 `1mag_cal_2step2.0.lua` 拷到飞控 SD 卡 `APM/scripts/` 目录。
3. 重启飞控，地面站应出现 `磁罗盘两步校准v2.2 已加载`。
4. 远离金属/电机大电流场景；周围 1m 内无强磁干扰；电池接好但**未解锁**。

## 3. 测试用例与预期结果

### 用例 1：解锁中误触保护
* **操作**：飞机解锁状态下故意让 pitch < -60°（不会真这样飞，仅在地面调试时倾倒机身模拟）。
* **预期**：脚本不进入触发流程，磁偏置参数无变化。

### 用例 2：完整两步式校准（核心）
* **操作**：保持上锁状态，按以下顺序完成校准：
  1. **预触发**：把机身机头朝下 ~80–90° 立起来。
     地面站立即提示 `磁罗盘:机头朝下 保持5秒触发`。
  2. **触发**：保持机头朝下 ≥5s。
     提示 `第1步:机头朝下转一圈`，校准已启动。
  3. **阶段 1 (0~25s)**：保持机头朝下，绕**世界 Z 轴**慢速转一圈。
  4. **阶段 2 (25~50s)**：提示 `第2步:水平转一圈`。
     **把机身放平**，再绕 yaw 慢速转一圈。
  5. **阶段 3 (50~65s)**：提示 `磁罗盘:保持静止 等待保存`。
     机身水平静止 10–15s，让飞控完成最终拟合。
  6. **完成**：飞控自身推 `MAG_CAL_REPORT`：
     - `cal_status = 4` 且 `autosaved = 1` → 校准成功，`COMPASS_OFS_X/Y/Z`、`COMPASS_DIA_*`、`COMPASS_ODI_*` 已自动写入。
       脚本检测到 OFS 变化后**立刻**播报 `磁罗盘成功 偏置=<x>,<y>,<z>`（不必等到 65s）。
     - `cal_status = 5/6/7` → 失败，由于 `retry=1`，飞控会自动重启采样，OFS 不变，脚本**不会**播报成功。
  7. **65s** 状态机进入 DONE：
     - 已捕获过成功 → 提示 `磁罗盘:完成 放平可再次触发`。
     - 一直没变化 → 提示 `磁罗盘失败:偏置未保存`，请按"4. 常见失败原因"排查。
  8. **恢复**：把机身放平 ≥2s，提示 `磁罗盘:已就绪 可再次触发`，可以再做一次。

### 用例 3：不到 5s 中断触发
* **操作**：把机头朝下 ~3s 后又恢复水平。
* **预期**：脚本不会启动校准，磁偏置参数保持原值；下次重新计时。

### 用例 4：校准中误解锁保护
* **操作**：用例 2 进行中尝试解锁。
* **预期**：脚本立即取消校准并提示 `磁罗盘:已取消 已解锁`；正常情况下飞控自身的预检也会因为校准未完成而拦截解锁。

### 用例 5：连续触发隔离
* **操作**：用例 2 完成（DONE）后，在还没把机身放平到 `pitch > -30°` 持续 2s 的情况下，立刻又把机身倒立。
* **预期**：脚本不会立刻重新触发，必须先把机身放平 2s 才会进 IDLE 重新接受触发。

### 用例 6：启动失败保护
* **操作**：模拟飞控不接受命令（如校准已经在运行中），nose-down 5s 后触发。
* **预期**：地面站提示 `磁罗盘:启动失败(N)`，状态机进入 DONE，**必须先把姿态放平**才能再次尝试，**不会持续刷屏重试**。

### 用例 7：成功后效果验证
* **操作**：用例 2 成功后，重启飞控（让 EKF 重新初始化）。
* **预期**：
  1. `COMPASS_OFS_X/Y/Z` 落在合理范围（|offset| < 600 mGauss 较好；> 1000 通常说明附近还有铁磁干扰）。
  2. 解锁前 EKF compass innovation 处于绿色；缓慢转动机体观察 yaw 跟随真实方向无偏差。
  3. 飞行测试时无 "EKF compass variance" 警告。

## 4. 常见失败原因与处理

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 没有出现 `磁罗盘:机头朝下 保持5秒触发` | pitch 没到 -60° / AHRS 还没就绪 | 把机身倾得更陡（接近垂直）；启动后等 10s 让 EKF 收敛 |
| 提示 `磁罗盘:启动失败(N)` | 已有校准在跑 / `COMPASS` 未启用 / 罗盘 unhealthy | 等几秒重发；或检查 `COMPASS_USE` / `COMPASS_HEALTHY`。返回值 4=DENIED, 5=UNSUPPORTED |
| `MAG_CAL_REPORT` 反复 `BAD_RADIUS` | 拟合半径不对，环境磁场异常 | 换个无干扰的开阔场地重试 |
| `BAD_ORIENTATION` | `COMPASS_AUTO_ROT=2/3` 检测到罗盘安装方向不对 | 修正 `COMPASS_ORIENT` 或暂时把 `COMPASS_AUTO_ROT=0` |
| `cal_status=5` (FAILED) 且 `fitness > 32` | 两圈转得太快/采样不够 | 转得慢一点（每圈 20–25s），或把 `T_STEP1_END_MS / T_STEP2_END_MS` 调大 |
| 偏置 > `COMPASS_OFFS_MAX` | 机身金属/电流环境太差 | 换位置；或视情况进一步放宽 `COMPASS_OFFS_MAX` |

## 5. 阈值如何调整

脚本顶部的常量按需修改：

| 常量 | 默认 | 含义 |
|---|---|---|
| `TRIG_PITCH_RAD` | `math.rad(-60)` | 机头朝下触发阈值。设得更负（如 `-75°`）触发更严格 |
| `TRIG_HOLD_MS` | `5000` | 触发前需要保持的时间 |
| `RECOVER_PITCH_RAD` | `math.rad(-30)` | 完成后视为已恢复水平的阈值 |
| `RECOVER_HOLD_MS` | `2000` | 恢复后需要保持的时间，避免姿态抖动反复触发 |
| `T_STEP1_END_MS` | `25000` | nose-down 转圈提示时长 |
| `T_STEP2_END_MS` | `50000` | 水平转圈结束提示时刻（自启动起算） |
| `T_HOLD_END_MS` | `65000` | 静止保存等待结束时刻 |

> 如果操作员转得慢或机身大，建议把 `T_STEP1/2/HOLD` 各加 5–10 秒，让采样更充分。

## 6. 与传统 6 面旋转校准的差异

| 维度 | 6 面旋转 (MP 引导) | 本脚本两步式 (姿态触发) |
|---|---|---|
| 触发方式 | 地面站点 Start | nose-down 5s 自动 |
| 操作动作 | 6 个朝向各转一圈 | nose-down 1 圈 + 水平 1 圈 |
| 球面覆盖 | 接近全覆盖 | 2 个不共面圆 |
| 拟合容差 | `CAL_FIT=16` 足够 | 需 `CAL_FIT=32` (Relaxed) |
| 时间 | ~2–3 分钟 | ~50–65 秒 |
| 适用场景 | 高精度作业首次校准 | 现场快速复校、单人外场作业 |

需要更高精度时，仍建议偶尔用 Mission Planner 做一次完整 6 面校准；本脚本面向**快速复校**和**单人外场**场景。
