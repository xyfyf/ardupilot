# ELRS/CRSF 回传对接（AppID 0x5010）

飞控：`SERIAL_PROTOCOL=23`（CRSF），`RC_OPTIONS` bit8=1（passthrough 遥测）。  
当前固件帧长 **`0x0F`**（含 2 字节扩展告警 + 4 字节通道映射）；旧版 **`0x09`**（仅 4 字节 data，兼容读前 4 字节即可）。

---

## 一、整帧字节定义（当前固件 len=0x0F）

| 序号 | HEX | 含义 |
|:---:|:---:|:---|
| 0 | `C8` | 发端：飞控 |
| 1 | `0F` | 长度：从 `type` 到 CRC 共 15 字节 |
| 2 | `80` | 帧类型：AP 自定义遥测（旧固件可能 `7F`） |
| 3 | `F0` | 子类型：单条 Passthrough |
| 4 | `10` | AppID 低字节 |
| 5 | `50` | AppID 高字节 → **0x5010** |
| 6 | `B0` | data 字节 0（uint32 最低字节） |
| 7 | `B1` | data 字节 1 |
| 8 | `B2` | data 字节 2（避障参数） |
| 9 | `B3` | data 字节 3（低电量标志） |
| 10 | — | **payload[4]** 扩展告警 1 |
| 11 | — | **payload[5]** 扩展告警 2 |
| 12 | — | **payload[6]** 通道映射（CH7 低4位 / CH8 高4位） |
| 13 | — | **payload[7]** 通道映射（CH9 低4位 / CH10 高4位） |
| 14 | — | **payload[8]** 通道映射（CH11 低4位 / CH12 高4位） |
| 15 | — | **payload[9]** 通道映射（CH13 低4位 / 预留=0 高4位） |
| 16 | — | CRC8 |

旧版 len=`09`：无序号 10~16，data 后直接 CRC。

---

## 二、data 四字节（B0~B3）位定义

小端：`dword = B0 | (B1<<8) | (B2<<16) | (B3<<24)`

| 位域 | 含义 |
|------|------|
| bit [15:0] | 前向距离，**cm**；无效时为 0 |
| bit [19:16] | `AVOID_MARGIN`，0~15，单位 m |
| bit [23:20] | `AVOID_DIST_MAX`，0~15，单位 m |
| bit [31:28] | 低电量：**非 0** = 当前电压低于阈值 |

**B2 拆分**：高 4 位 = `AVOID_DIST_MAX`，低 4 位 = `AVOID_MARGIN`。  
**B3**：仅高 4 位（bit28）表示低电。

**低电量判定规则**：
- 触发：当前电压 < `max(BATT_LOW_VOLT, BATT_CRT_VOLT)`
- 清除：电压回升到阈值 +0.1V 以上（0.1V 滞回防抖）
- **不依赖飞控 failsafe 锁存**：电压恢复后自动清零，无需重启或地面站 `BATTERY_RESET`

## 三、payload[4] ~ payload[9] bit 定义

### payload[4]

| bit | 含义 |
|:---:|:---|
| 0 | 风速过大，请尽快降落或返航 |
| 1 | 您已接近禁飞区，飞行器将自动迫降（**当前固件不置位**） |
| 2 | 指南针异常，请校准（**仅在未解锁时检查**；0 罗盘直接报异常；1 罗盘按 PreArm `compass_checks` 口径判定（healthy / configured / offsets / 磁场强度 / 地磁模型差，受 `ARMING_CHECK` bit2 控制）；2~3 罗盘冗余场景由 EKF 处理，不上报） |
| 3 | IMU 异常，请重启飞行器 |
| 4 | 电子围栏已触发 |
| 5 | GNSS 已丢失，请立即降落 |
| 6 | 1 号动力油门丢失 |
| 7 | 2 号动力油门丢失 |

### payload[5]

| bit | 含义 |
|:---:|:---|
| 0 | 3 号动力油门丢失 |
| 1 | 4 号动力油门丢失 |
| 2 | 5 号动力油门丢失 |
| 3 | 6 号动力油门丢失 |
| 4~7 | 保留，发 0 |

**bit=1 表示告警，=0 正常。**

**置位条件：** `initialising=0` 且 `pre_arm_check=1`（飞控自检通过）后才会置位；此前 payload[4]/[5] 固定为 `00`。

### payload[6] ~ payload[9]（通道映射）

每字节按高低各 4 bit 存放两个通道的功能编码。

**映射对应表：**

| 编码 | 含义 |
|:---:|:---|
| `0000` | 无映射 |
| `0001` | 雷达开关（`RCx_OPTION=300 SCRIPTING_1`） |
| `0010` | 防误触开关（`RCx_OPTION=221 PRE_MOTOR_ESTOP`） |
| `0011` | 锁桨开关（`RCx_OPTION=31 MOTOR_ESTOP`） |
| `0100` | 返航开关（`RCx_OPTION=4 RTL`） |

**字节布局：**

| 字节 | bit | 含义 |
|:---:|:---:|:---|
| payload[6] | 0~3 | Channel7 的映射 |
| payload[6] | 4~7 | Channel8 的映射 |
| payload[7] | 0~3 | Channel9 的映射 |
| payload[7] | 4~7 | Channel10 的映射 |
| payload[8] | 0~3 | Channel11 的映射 |
| payload[8] | 4~7 | Channel12 的映射 |
| payload[9] | 0~3 | Channel13 的映射 |
| payload[9] | 4~7 | 预留，发 0 |

Channel7~13 代表的是 0~15 通道的第 7~13 个通道（`RC7_OPTION`~`RC13_OPTION`）。  
飞控每秒更新一次缓存；对应参数无效或未识别时半字节发 `0000`。

## 四、样例解读

### 定版参数配置（EFT_CAAC defaults.parm）

| 参数 | 值 | 含义 |
|------|----|------|
| RC7_OPTION | 300 | 雷达开关（SCRIPTING_1） |
| RC8_OPTION | 4 | 返航开关（RTL） |
| RC11_OPTION | 221 | 防误触（PRE_MOTOR_ESTOP） |
| RC12_OPTION | 31 | 锁桨（MOTOR_ESTOP） |

### 样例 1（正常测距，0x0F）

```text
C8 0F 80 F0 10 50 D6 00 53 00 00 00 41 00 32 00 XX
```

| 字段 | 值 | 解读 |
|------|-----|------|
| data | `D6 00 53 00` → `0x005300D6` | 距离 **214 cm**；AVOID_MAX=5 m，MARGIN=3 m；未低电 |
| payload[4/5] | `00 00` | 无扩展告警 |
| payload[6] | `0x41` | CH7 低4位=`0001`=雷达开关；CH8 高4位=`0100`=返航开关 |
| payload[7] | `0x00` | CH9=无映射；CH10=无映射 |
| payload[8] | `0x32` | CH11 低4位=`0010`=防误触；CH12 高4位=`0011`=锁桨 |
| payload[9] | `0x00` | CH13=无映射；高4位预留=0 |

**注**：实际帧中 payload[6~9] 逐字节按定版参数自动填充，遥控器侧解析各半字节即可。

### 样例 2（告警，0x0F）

```text
C8 0F 80 F0 10 50 00 00 53 00 24 00 XX XX XX XX XX
```

| 字段 | 值 | 解读 |
|------|-----|------|
| data | `00 00 53 00` → `0x00530000` | 距离 **0 cm**；AVOID_MAX=5 m，MARGIN=3 m；未低电 |
| payload[4] | `0x24` | bit2=1 → **指南针异常** |
| payload[5] | `0x00` | 无电机丢失告警 |
| payload[6~9] | 同上 | 通道映射（同定版参数） |
